ASSUMPTIONS MADE
- Blank attack-pattern cells in Testbed Data - Attacked.csv were forward-filled.
- Yang3 in the pre-mitigation file was normalized to Yang.
- Dash and footnote-marked values were parsed as missing or numeric values as appropriate; missing distances were not replaced with zero.
- Vehicle-level final-stop missed_stop_outcome=1 when final stopping distance is missing or exceeds 0.8 m; a missing first-detection value alone is not counted as a missed stop outcome.
- Pre- and post-mitigation runs were treated as independent groups.
- Bootstrap confidence intervals used 10,000 resamples and random seed 42.
- Bootstrap confidence intervals marked NA have fewer than 2 valid numeric values.
- 7_Mitigations.csv was treated as post_mitigation for seven additional printed designs; observed run counts were used as recorded: Chen1=6, Chen2=6, Chen3=6, Eykholt1=6, Eykholt2=6, Eykholt3=6, Lu1=6.
- 7_Mitigations.csv does not contain route completion time; route completion summaries are therefore NA.
