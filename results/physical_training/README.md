# Physical-Mitigation Training Run

`results.csv` and `results.png` are copied from the later 100-epoch fine-tuning run associated with `models/pytorch/qcar_physical_mitigation_best.pt`. The 244/62 image split and original labels are under `data/physical_training/`; configuration is under `configs/training/`. These validation curves describe training and model selection, not independent held-out generalization.

The exact curve embedded as Figure 9 in the editorial PDF has not been linked to this CSV by a saved figure-generation record. Do not claim exact figure provenance without checking that source.
