# Artifact Availability

## Review-Stage Snapshot

This review-stage repository contains documentation only. It provides a project landing page, a manuscript-based reproducibility summary, and software-environment information for the Quanser QCar deployment described in the manuscript.

The review-stage snapshot intentionally does not include:

- Experimental source code or deployment scripts
- Trained model checkpoints or TensorRT engine files
- Datasets, images, labels, or annotations
- Raw or processed experimental records
- Statistical-analysis scripts or generated statistical assets
- Training, validation, or held-out evaluation outputs
- Logs, videos, archives, or unpublished result tables
- Machine-specific configuration or credentials

## Planned Full Release

The complete experimental source code, trained model weights, dataset and annotations, statistical analysis assets, and execution instructions are planned for release through this repository upon acceptance of the manuscript.

The contents and metadata of that future release will be reviewed separately for scientific consistency, third-party attribution, privacy, file-size constraints, and repository organization before publication.
